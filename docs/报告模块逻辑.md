## 2. 报告生成总体链路

```text
NgsReportController.createReport
  -> PyReportServiceImpl.createReport2
    -> 读取 analysis_report / sample_file / data_file_status / rp_* / mm_* / nkb* / module*
    -> 填充 ReportTemplate
    -> PyAnalysisReportTemplateUtil.getFreeMarker
      -> ReportTemplate -> Map<String,Object> -> tempJson.json
      -> TemplateUtil2.stat_report
        -> python3 generate_report.py 模板 JSON 输出docx
```

关键控制表：

- `template_conf`
- `module_conf`
- `mod_common_note`
- `mod_product_desc`
- `mod_references`
- `gene_panel`

模块控制核心事实：

1. **章节是否存在**，主要由 `template_conf` 的布尔开关控制。
2. **章节中文案**，主要由 `mod_common_note` / `mod_product_desc` / `mod_references` / `module_conf` 控制。
3. **章节数据**，主要由 `sample_file`、`analysis_report`、`data_file_status`、`rp_*`、`mm_*`、`nkb*` 产生。
4. **最终模板渲染**，由 `generate_report.py` 读取 JSON 顶层字段和 `note/reportInfo/product/references` 等结构完成。

## 6.4 Java 处理逻辑

### 6.4.1 报告名称 `reportInfo.name`

位置：

- `generateReportInfoData(...)`

逻辑：

- 来源：`templateConf.getReport_name()`
- 如果客户是慧尔斯且癌种包含 `10155`，会把“实体瘤”替换为“肠癌”
- 如果有 `PDInfo`
  - `{{PD-L1}}` 替换为 `+PD-L1`
  - 或把“检测报告”替换为“+PD-L1检测报告”
- `{{sample_type}}` 替换成翻译后的样本类型

### 6.4.2 产品描述 `product.productDescList`

位置：

- `generateProductDesc(...)`

逻辑：

1. 查询模板级产品描述 `mod_product_desc`
2. 若是 `novopm2_tis_wesplus` 且样本类型为组织，插入 GIS/HRD 描述
3. 若有 `pd` 数据，追加 `通过免疫组化检测 PD-L1 表达`
4. 按 `\r\n` 拆为第一部分列表
5. 再查询 `通用-单样本/双样本` 描述，按模块开关裁剪：
   - 无 `chemo_anal` → 删除 `、化疗药物`
   - 无 `MSI` → 删除 `、免疫药物`
   - 非甲状腺/非黑色素瘤或开关关闭 → 删除 `、预后评估`
   - 双样本无泌尿模块 → 删除内分泌/神经内分泌/疾病预后相关描述
   - 非子宫内膜癌分型模块 → 删除 `子宫内膜癌分子分型`
   - 非肉瘤模块 → 删除 `肉瘤辅助诊断提示`
   - 无 `mrd` → 删除 `和患者MRD动态监测提供参考`
   - 单样本无 `cr_drug_tip` → 删除 `和遗传风险`

DNA QC：

- `tumorcellcontent`
- `DNA_total`
- `DNA_degradation`
- `outbound_quantity`
- `plane_data`
- `sequencing_depth`
- `coverage_uniformity`
- `coverage`
- `genome_alignment`
- `base_quality`

质量判断：

- 组织：`>=500 合格 / 400-499 警戒 / <400 不合格`
- 血液：`>=1500 合格 / 1000-1499 警戒 / <1000 不合格`

RNA QC：

- `total_reads >= 12000000 合格`
- `10000000-11999999 警戒`
- `<10000000 不合格`

综合质量：

- `getWorstAssessment(dnaAssessment, rnaAssessment)`

附录类型：

- `sampleQualityControl.type = isblood/tissue`

## 18.4 文案 SQL

```sql
SELECT cancer_title, note
FROM mod_common_note
WHERE module = 'qc'
  AND type = #{DNA/RNA/HRD}
```

Java 中 `type1` 判定：

- `panelType.contains("RNA")` → `RNA`
- `panelType.contains("HRD") || sampleType == tissue` → `HRD`
- 默认 `DNA`
